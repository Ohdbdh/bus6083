Prompt 模式參考

R-C-C-O 系統提示詞公式

好的系統提示詞包含四個組件：

組件說明範例
R — 角色（Role）定義 AI 身份與受眾你是一位 [特定專業角色]，服務對象為 [受眾類型]
C — 核心指令（Core Instruction）定義主要職責與規則你的主要職責為 [核心目標]
C — 限制條件（Constraints）設定必須遵守的限制你必須遵守 [限制條件 1]、[限制條件 2]
O — 輸出格式（Output format）定義風格與語氣[風格] / [語氣]

負責任 AI 客服 Prompt 設計原則

  • 限制來源：只根據知識庫回答，不可使用其他來源
  • 要求引用：必須指出依據的文件段落或條款編號
  • 誠實拒答：知識庫不足時必須明確表示無法確認
  • 指定語言：明確指定輸出語言與語氣
  • 禁止編造：不可自行推測或編造答案

Chatflow 風控設計模式

用户提問 → 意圖分類器
    ├── 低風險 → RAG 檢索 → LLM 生成回答
    └── 高風險 → 固定回復 / 轉人工

分類標準：

  • 低風險：資訊查詢、政策諮詢、一般問題
  • 高風險：金錢交易、退款、投訴、法律索賠

網站生成 Prompt 模板

簡短模板

建立一個 [頁數]-頁的網站，主題為 [目的]。
受眾：[對象]。風格：[風格]。
圖片：圖片網址。手機響應式設計。

完整模板

建立一個 [頁數]-頁的網站，主題為 [目的]。
目標受眾：[對象]。
頁面：[頁面列表及簡短說明]。
關鍵功能：[功能列表]。
圖片：使用如 Unsplash 等免費線上圖庫。
風格：[風格]。主色調：[色盤]。字型：[字型描述]。
手機響應式設計。包含導航選單。
