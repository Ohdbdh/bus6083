# 模組七：UI/UX & Vibe Coding

## 1. 什麼是 UI/UX 以及它為何重要？

### UI（User Interface，使用者介面）
應用程式的「外觀」——顏色、字型、佈局、按鈕。

### UX（User Experience，使用者體驗）
應用程式的「使用感受」——是否易於操作？邏輯是否清晰？運行速度是否流暢？

| 情境 | 評價 |
|------|------|
| 一個精美但導航混亂的應用程式 | 糟糕的 UX |
| 一個簡潔但能精準滿足使用者需求的應用程式 | 優秀的 UX |

> **良好的設計並非裝飾，而是溝通。**

## 3. 舊模式 vs 新模式

> 您不需要精通程式碼。您需要清楚知道自己想要什麼，並能清晰地描述出來。

| 比較項 | 舊模式 | 新模式 |
|--------|--------|--------|
| 技能 | 學習 HTML/CSS/JS（需數月） | 以語言描述（僅需數分鐘） |
| 成本 | 聘請開發人員（需高昂成本） | 向 AI 發出指令（免費） |
| 除錯 | 逐行修復程式錯誤 | 告知 AI 哪裡出了問題 |
| 版本管理 | 需要版本控制 | 透過對話進行疊代 |

## 5. Google Gemini Canvas

- **工具連結**：https://gemini.google.com/
- **Canvas 功能**：將靜態結果轉化為互動式應用程式或網站
- **模型選擇**：
  - **Pro**：生成更優質的結果，但等待時間較長（約 5 分鐘）
  - **Flash**：速度快，節省積分

### 介面操作
1. 在輸入框中輸入 Prompt
2. 選擇 Canvas 模式
3. 選擇模型（Pro 或 Flash）
4. 生成後可即時預覽並透過對話修改

## 8. 常見錯誤與簡易修復

| # | 錯誤 | 修復方法 |
|---|------|----------|
| 01 | **按鈕無反應** | 將具體錯誤描述給 Gemini，要求其修正程式碼。如果仍然無效，嘗試重新生成網站 |
| 02 | **視覺錯誤或角色圖片不正確** | 要求 Gemini 尋找免費圖庫相片（可自由使用），或直接貼上圖片網址 |
| 03 | **無法儲存進度** | 這是目前的一個限制，因為 Google Gemini Canvas 尚未具備帳號登入與進度儲存功能 |

## 10. 實戰範例：智能排班系統

### Prompt 指令

> 請在 Canvas 中幫我構建一個現代極簡風格的【員工報更與智能排班系統】，單頁面 HTML/JS 原型：
>
> 1. 員工端（Worker View）：
>    - 輸入員工姓名與工號
>    - 交互表格：勾選下週一至週日（早班 09-13 / 午班 13-18 / 晚班 18-22）的空閒時段
>
> 2. 管理員端（Admin View）：
>    - 儀表板展示已報更員工名單與時段熱力圖
>    - 提供【一鍵智能排班】按鈕，依據每班至少 2 人的規則自動分配
>    - 高亮標出人手不足的時段（報警提示），並支持導出排班結果

### 實戰要點
- **體驗工具**：Google Gemini (https://gemini.google.com/)
- **即時可交互**：學生可在瀏覽器直接點擊勾選、切換管理員視角、測試一鍵排班邏輯
- **零成本敏捷部署**：從想法到可用原型，耗時不到 3 分鐘
