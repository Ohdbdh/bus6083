# 模組三：教大 MaaS 平台指南

## 1. 平台登入

- **平台連結**：https://maas.eduhk.hk/
- **登入方式**：直接以教大學生帳戶登入（支援 Microsoft Login）

---

## 2. 平台基本功能

MaaS 平台的主要介面分為：

| 功能 | 說明 |
|------|------|
| **功能目錄（Menu）** | 側邊欄包含 Chat、Studio、Dataset、Toolkit、Account |
| **應用程式分類** | All / Simple App / Workflow / Plugin |
| **建立新應用程式** | 點擊 `+ Create` 可建立 Simple App、Workflow、Plugin 等 |

---

## 3. 查閱配額

- **操作指引**：點擊「帳戶」（Account）>「?」即可查看各模型配額
- **配額限制**：每次提問 ≈ 1,000 個 Token，每月限額為 **1,000 點 AI 積分**

### 錯誤處理
若預設模型出現調用錯誤（如 401 身份驗證失敗），請從模型清單中切換其他模型，建議優先選取**運算成本較低的選項**。

---

## 4. 數據集建立

### 步驟一：進入數據集
1. 在側邊欄選擇「數據集」（Dataset）
2. 點擊「建立」（Create）

### 步驟二：選擇資料來源
1. 選擇「文本數據集」（Text Dataset）
2. 選擇資料來源：
   - **Local File**：上載 PDF、TXT、DOCX 等格式
   - **Web Link**：從網頁連結匯入
   - **Custom Text**：直接輸入文字

### 步驟三：核心模型架構配置

| 模型類型 | 功能 | 免費選項 |
|----------|------|----------|
| **索引模型（Index Model）** | 將文本轉換為數值向量嵌入，支援語義檢索 | embedding-3 (FREE) |
| **文檔讀取模型（Document Reading Model）** | 從 PDF、Word 等格式中解析並提取文字 | GLM-4-air (FREE) |
| **圖像理解模型（Image Understanding Model）** | 識別並分析知識庫圖像中的內容與語意 | GLM-4v-flash |

### 備用模型推薦

| 類型 | 備用模型 |
|------|----------|
| 索引模型 | jina-embeddings-v3、baai/bge-m3 |
| 文本理解模型 | Deepseek-V4-Flash |
| 圖像理解模型 | Llama-4-Maverick (Meta) |

### 步驟四：分段與處理設定

| 模式 | 說明 |
|------|------|
| **分段模式（Chunk）** | 將文檔拆解為長度均勻的語義段落，適用於覆蓋面較廣的通識或日常知識檢索 |
| **問答對模式（QA）** | 由 AI 預先將內容提煉為一問一答的形式；檢索命中率極高，但可能在轉換過程中遺失部分原文脈絡或細節 |

其他設定：
- **Blocking conditions**：原文大於 1000 字元時分段
- **Index enhancement**：可開啟索引加標題、自動生成補充索引、自動圖像索引

---

## 5. 檢索測試

於正式上線前可進行檢索測試，評估知識庫的召回效能與精準度。

### 搜尋模式

| # | 模式 | 說明 |
|---|------|------|
| 1 | **語義搜尋** | 依據概念意涵進行比對，而非死板匹配關鍵字 |
| 2 | **全文搜尋** | 傳統精確文字匹配，僅檢索包含特定關鍵字的內容 |
| 3 | **混合搜尋** | 同時結合語義比對與關鍵字檢索，兼顧泛化理解與專有名詞的命中率 |
| 4 | **結果重排（Re-Rank）** | 對初步檢索出的文檔區塊進行二次深度相關度評分，將最核心關鍵的答案置頂 |

### 混合搜尋配置
- 混合搜尋比例滑桿：0.5
- 結果重排：開啟，模型可選 Llama-Rank
