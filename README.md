## 使用方式

1. **課前預習**：閱讀當週的 `notes/` 文檔
2. **課中操作**：按 `notes/` 中的步驟在平台實作
3. **課後練習**：完成 `exercises/` 中的練習任務
4. **速查模板**：上課時隨時打開 `templates/` 中的模板複製使用
