## 從「系統安全」到「使用者能正確使用」

前面七節我們解決的是「系統是否安全」——知識庫、RAG、Chatflow 風控、安全治理。但一個安全的系統，如果介面設計糟糕，使用者可能會：

- 誤以為 AI 的回答是最終裁決（過度信任風險，見 Note 7）
- 無法找到「轉人工」的入口
- 看不到 AI 回答的引用來源，無法判斷可信度

> **UI/UX 的任務不是讓系統「更漂亮」，而是讓安全能力「被使用者看見並正確使用」**。

本節是獨立的技能模組，但目標明確：用 Vibe Coding 快速生成一個客服 UI 原型，把前面構建的安全能力呈現給使用者。

---

## 什麼是 UI/UX？

| 概念 | 定義 | 關注點 |
|------|------|--------|
| **UI（User Interface）** | 應用程式的「外觀」 | 顏色、字型、佈局、按鈕 |
| **UX（User Experience）** | 應用程式的「使用感受」 | 是否易於操作？邏輯是否清晰？速度是否流暢？ |

> **良好的設計並非裝飾，而是溝通。**

| 情境 | 評價 |
|------|------|
| 精美但導航混亂 | 糟糕的 UX |
| 簡潔但精準滿足需求 | 優秀的 UX |

## Vibe Coding：用自然語言寫程式

### 舊模式 vs 新模式

| 比較項 | 舊模式 | 新模式 |
|--------|--------|--------|
| 技能 | 學習 HTML/CSS/JS（數月） | 以語言描述（數分鐘） |
| 成本 | 聘請開發人員 | 向 AI 發出指令（免費） |
| 除錯 | 逐行修復 | 告知 AI 哪裡出了問題 |
| 版本管理 | 需要版本控制 | 透過對話疊代 |

### Vibe Coding 流程

1. 用自然語言描述應用程式
2. AI 生成可運作的 HTML/CSS/JS
3. 即時預覽結果
4. 透過對話要求修改
5. 重複直到滿意
6. 複製程式碼 / 分享連結

## 實作：生成一個 RAG 客服 UI 原型

這不是泛泛的「生成一個網站」，而是把你前面構建的 RAG + Chatflow 系統包裝成使用者介面。一個合格的客服 UI 應包含以下元素：

### 必要 UI 元素（對應本週安全設計）

| UI 元素 | 對應的安全需求 | 來源 |
|---------|---------------|------|
| 顯示引用來源（條款編號） | 審計追溯 | Note 3, 5 |
| 顯示「根據現有文件無法確認」狀態 | 誠實拒答 | Note 5 |
| 高風險問題顯示「轉人工 / 專員跟進」 | 硬隔離 | Note 6 |
| 回饋按鈕（有幫助 / 不準確） | 持續監控 | Note 7 |
| 清楚區分 AI 回答與人工處理 | 人機協作 | Note 1, 7 |

### Prompt 指令範例

```
請在 Canvas 中幫我構建一個現代極簡風格的【航空公司 AI 客服介面】，
單頁面 HTML/JS 原型，需要包含：

1. 對話區：用户輸入問題，AI 回覆時附帶「引用來源：條款 #XX」標籤
2. 當 AI 無法確認時，顯示黃色提示框：「根據現有文件無法確認，建議聯絡客服專員」
3. 當問題屬於高風險（退款/索賠/投訴）時，顯示藍色提示框：「您的訴求已收到，專員將在 24 小時內致電核實」
4. 每條 AI 回覆下方有「👍 有幫助 / 👎 不準確」回饋按鈕
5. 右上角有「轉人工客服」按鈕，隨時可切換

風格：現代極簡、淺色背景、圓角卡片。
手機響應式設計。
```

### 成效
- 學生可在瀏覽器直接交互測試
- 從想法到可用原型，耗時不到 3 分鐘
- 生成出的 UI 直接體現了本週學到的安全設計原則

## 網站生成 Prompt 公式

除了客服 UI，你也可以用同樣的方法生成其他類型的網站。

### 四大要素

| 要素 | 說明 |
|------|------|
| **目的與主題** | 明確定義網站目標 |
| **內容結構** | 指定所需內容與頁面 |
| **功能需求** | 進度追蹤、互動式彈出視窗、動態資訊 |
| **視覺風格** | 描述設計美學 |

### 簡短模板

```
建立一個 [頁數]-頁的網站，主題為 [目的]。
受眾：[對象]。風格：[風格]。
圖片：圖片網址。手機響應式設計。
```

### 完整模板

```
建立一個 [頁數]-頁的網站，主題為 [目的]。
目標受眾：[對象]。
頁面：[頁面列表及簡短說明]。
關鍵功能：[功能列表]。
圖片：使用如 Unsplash 等免費線上圖庫。
風格：[風格]。主色調：[色盤]。字型：[字型描述]。
手機響應式設計。包含導航選單。
```

### 風格選項

極簡風格、深色模式、紅金傳統風、粉彩可愛風、復古報紙風、企業專業風、像素藝術、卡通、極簡平面風、深色霓虹風

### 使用自己的圖片
提供圖片網址（Google Search / Unsplash / Google Drive 連結），並告知 AI 放置位置。

## 常見錯誤與修復

| # | 錯誤 | 修復方法 |
|---|------|----------|
| 1 | 按鈕無反應 | 描述具體錯誤給 Gemini，要求修正程式碼；無效則重新生成 |
| 2 | 圖片不正確 | 要求 Gemini 使用免費圖庫，或直接貼上圖片網址 |
| 3 | 無法儲存進度 | Gemini Canvas 目前不支援帳號登入與進度儲存 |
