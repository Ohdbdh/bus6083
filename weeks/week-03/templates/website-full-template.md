# 模板：網站生成 — 完整模板

> 使用場景：在 Google Gemini Canvas 中生成結構完整的網站。

---

## Prompt 模板

```
建立一個 [頁數]-頁的網站，主題為 [目的]。
目標受眾：[對象]。
頁面：[頁面列表及簡短說明]。
[主視覺區 (Hero section), 主要內容區 (Main section)]
關鍵功能：[功能列表]。
圖片：使用如 Unsplash 等免費線上圖庫。
風格：[風格]。主色調：[色盤]。字型：[字型描述]。
手機響應式設計。包含導航選單。
```

---

## 使用範例

```
建立一個 4-頁的網站，主題為 香港非物質文化遺產介紹。
目標受眾：對香港文化有興趣的本地及國際訪客。
頁面：
- 首頁：主視覺區展示香港文化遺產標題與統計數據
- 遺產列表：展示各項非物質文化遺產的分類與簡介
- 詳細介紹：點擊查看各項遺產的詳細說明（互動式彈出視窗）
- 關於我們：項目背景與聯絡方式
關鍵功能：進度追蹤、互動式彈出視窗、動態資訊顯示。
圖片：使用 Unsplash 免費圖庫。
風格：深色模式、極簡風格。主色調：深藍色配金色。字型：無襯線體。
手機響應式設計。包含導航選單。
```
