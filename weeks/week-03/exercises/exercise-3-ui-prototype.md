# 練習三：UI 原型設計

## 目標
使用 Google Gemini Canvas 透過 Vibe Coding 快速生成一個互動式網站原型。

## 前置條件
- 已有 Google 帳號
- 可訪問 Google Gemini (https://gemini.google.com/)
- 已閱讀 [notes/08-ui-ux-vibe-coding.md](../notes/08-ui-ux-vibe-coding.md)

## 步驟

### Part A：構思你的應用
選擇一個你感興趣的主題，例如：
- 香港非物質文化遺產介紹網站
- 個人作品集
- 班級活動報名系統
- 餐廳推薦平台

### Part B：撰寫 Prompt
使用 [完整模板](../templates/website-full-template.md) 撰寫你的 Prompt。

### Part C：生成與疊代
1. 打開 Google Gemini
2. 選擇 Flash 模型（節省積分）
3. 在輸入框中貼上你的 Prompt
4. 點擊 Canvas 模式
5. 生成後預覽結果
6. 透過對話要求修改，例如：
   - 「把按鈕顏色改成紅色」
   - 「添加一個搜尋功能」
   - 「字型改成楷體」

### Part D：使用圖片
如需使用自己的圖片：
1. 上載圖片到 Google Drive，設定為「任何人可查看」
2. 複製分享連結
3. 在 Prompt 中告知 AI 圖片網址及放置位置

### Part E：發布分享
1. 點擊「分享」>「複製」
2. 將連結分享給同學查看

## 完成標準
- [ ] 成功生成一個多頁面網站
- [ ] 網站包含導航選單
- [ ] 網站支援手機響應式設計
- [ ] 至少包含一個互動功能（彈出視窗、按鈕等）
- [ ] 透過對話至少進行一次修改疊代

## 進階挑戰
- 嘗試不同的風格組合（如「粉彩可愛風」vs「深色霓虹風」）
- 嘗試加入語言切換功能（EN / 繁）
- 嘗試生成一個簡單的互動小遊戲（如 Tic-Tac-Toe）
