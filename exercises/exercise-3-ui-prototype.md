# 練習三：UI 原型設計

## 目標
使用 Google Gemini Canvas 透過 Vibe Coding 快速生成一個互動式網站原型。

## 前置條件
- 已有 Google 帳號
- 可訪問 Google Gemini (https://gemini.google.com/)

## 步驟

### Part A：構思你的應用
選擇一個你感興趣的主題，例如：
- 香港非物質文化遺產介紹網站
- 個人作品集
- 班級活動報名系統
- 餐廳推薦平台

### Part B：撰寫 Prompt
使用 [完整模板](../templates/website-full-template.md) 撰寫你的 Prompt。

**範例 Prompt：**
```
建立一個 3-頁的網站，主題為 香港非物質文化遺產介紹。
目標受眾：對香港文化有興趣的本地及國際訪客。
頁面：
- 首頁：主視覺區展示標題與統計數據
- 遺產列表：展示各項遺產的分類與簡介
- 詳細介紹：點擊查看詳細說明（互動式彈出視窗）
關鍵功能：互動式彈出視窗、動態資訊顯示。
圖片：使用 Unsplash 免費圖庫。
風格：深色模式、極簡風格。主色調：深藍色配金色。字型：無襯線體。
手機響應式設計。包含導航選單。
```

### Part C：生成與疊代
1. 打開 Google Gemini
2. 選擇 **Flash** 模型（節省積分）
3. 在輸入框中貼上你的 Prompt
4. 點擊 **Canvas** 模式
5. 生成後預覽結果
6. 透過對話要求修改，例如：
   - 「把按鈕顏色改成紅色」
   - 「添加一個搜尋功能」
   - 「字型改成楷體」

### Part D：使用圖片
如需使用自己的圖片：
1. 上載圖片到 Google Drive，設定為「任何人可查看」
2. 複製分享連結
3. 在 Prompt 中告知 AI 圖片網址及放置位置

### Part E：發布分享
1. 點擊「分享」（Share）>「複製」（Copy）
2. 將連結分享給同學查看

## 完成標準
- [ ] 成功生成一個多頁面網站
- [ ] 網站包含導航選單
- [ ] 網站支援手機響應式設計
- [ ] 至少包含一個互動功能（彈出視窗、按鈕等）
- [ ] 透過對話至少進行一次修改疊代

## 進階挑戰
- 嘗試不同的風格組合（如「粉彩可愛風」vs「深色霓虹風」）
- 嘗試加入語言切換功能（EN / 繁）
- 嘗試生成一個簡單的互動小遊戲（如 Tic-Tac-Toe）

## 常見問題排解

| 問題 | 解決方法 |
|------|----------|
| 按鈕無反應 | 描述具體錯誤給 Gemini，要求修正程式碼 |
| 圖片顯示不正確 | 使用 Unsplash 免費圖片或貼上圖片網址 |
| 無法儲存進度 | 這是 Gemini Canvas 目前的限制，可複製程式碼備份 |
